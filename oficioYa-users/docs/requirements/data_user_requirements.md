### Trabajador

| Dato                             | Descripción                                                                                                 | Requerimiento                                                                                                                                      | Vista             |
|----------------------------------|-------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------|-------------------|
| Nombre                           | El nombre del usuario que tiene como rol trabajador                                                         | Obligatorio                                                                                                                                        | Registro y perfil |
| Contraseña                       | Caracteres para verificar que el usuario inició sesión/se registró dentro de la plataforma                  | Obligatorio (mínimo de 12 caracteres, mínimo un carácter especial, mínimo una letra en mayúscula, mínimo una letra en minúscula, mínimo un número) | Registro y perfil |
| Foto                             | Sirve para saber la identidad del usuario que realiza distintos oficios                                     | Obligatorio                                                                                                                                        | Registro y perfil |
| Correo                           | Es la forma en que se reconocerá al usuario dentro de la plataforma                                         | Obligatorio (cualquier correo es admitido pero en el perfil NO se puede modificar después de registrado)                                           | Registro y perfil |
| Teléfono                         | El número de celular del usuario para ser contactado                                                        | Obligatorio (modificable y se puede tener más de un número)                                                                                        | Registro y perfil |
| Oficio principal                 | Es el trabajo primario por el que se caracteriza el usuario                                                 | Obligatorio                                                                                                                                        | Registro y perfil |
| Oficios secundarios              | Son otros trabajos adicionales que se enfoca el usuario                                                     | Opcional (aquí también se pueden adicionar las categorías especiales)                                                                              | Registro y perfil |
| Zona de cobertura                | Es el barrio en donde el usuario quiere realizar su oficio o donde se caracteriza por realizarlo allí       | Obligatorio (una sola cobertura)                                                                                                                   | Registro y perfil |
| Tarifa aproximada                | Es la cantidad de dinero que el usuario le cobra a un contratante por realizar su trabajo                   | Obligatorio                                                                                                                                        | Registro y perfil |
| Disponibilidad semanal           | Es la hora y fecha en el que el usuario se dedica a realizar su labor                                       | Obligatorio                                                                                                                                        | Registro y perfil |
| Galería de trabajos anteriores   | Son las fotos en donde se evidencia que el trabajador ha hecho la labor principal o los oficios secundarios | Obligatorio (para oficio primario: mínimo 3 y máximo 7, para oficios secundarios: mínimo 2 y máximo 5)                                             | Registro y perfil |
| Reseña                           | Formato de máximo 5000 caracteres para dar una evaluación al usuario trabajador                             | Opcional                                                                                                                                           | Perfil            |
| Cantidad de trabajos completados | Son las labores hechas correctamente por el usuario                                                         | Ninguno                                                                                                                                            | Perfil            |
| Calificación promedio            | Es la calificación en estrellas de la reputación del usuario                                                | Tener 1 trabajo completado como mínimo                                                                                                             | Perfil            |
| Suscripción                      | Forma de monetizar para que aparezca primero en búsquedas y acceder a estadísticas avanzadas de su demanda  | Ninguna                                                                                                                                            | Perfil            |
